# Delicious - Food Delivery Web Application

A full-stack food delivery web application developed using Java Servlets, JSP, JDBC, and MySQL.

## Key Features
- **User Authentication**: Secure customer login and session handling.
- **Menu & Cart Management**: Dynamic dish selection and real-time order calculation.
- **Live Order Tracking**: Interactive map integration using Leaflet.js.
- **Payment Gateway**: Support for Cash on Delivery (COD) and mock online transactions.

## Tech Stack
- **Backend**: Java, Servlets, JDBC
- **Frontend**: HTML5, CSS3, JavaScript, JSP, Leaflet.js
- **Database**: MySQL
- **Server**: Apache Tomcat
